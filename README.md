<h1 align="center"> SА — Система для кадастровых инженеров</h1>

## Описание

Мы разрабатываем прототип программной системы для кадастровых инженеров, предназначенной для автоматизированной работы с пространственными данными. Система будет оснащена специализированным инженерным инструментарием и интеллектуальным помощником на основе ИИ, что позволит сократить время обработки данных, минимизировать ошибки, повысить точность и упростить процесс землеустройства.

## Запуск

### Установить docker 
[Docker](https://www.docker.com/)
```bash
$ yarn install
```

## Compile and run the project

```bash
## Деплой
$ docker compose up 


```
