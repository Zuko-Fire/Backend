# Инструкция по использованию системы SA

## 📋 Что такое SA?

SA (Surveyor's Assistant) — это программа для кадастровых инженеров, которая помогает:
- Управлять проектами землеустройства
- Работать с географическими данными (полигонами, участками)
- Хранить документы и справочные материалы
- Совместно работать с коллегами

## 🚀 Как начать работу

### Шаг 1: Запуск системы

1. Убедитесь, что Docker установлен
2. Откройте терминал в папке проекта
3. Выполните команду:
   ```bash
   docker compose up --build -d
   ```
4. Дождитесь запуска всех сервисов

### Шаг 2: Создание аккаунта

1. Откройте Swagger документацию: http://localhost:4000/api
2. Найдите раздел "Authentication"
3. Нажмите на "POST /auth/register"
4. Нажмите "Try it out"
5. Заполните данные:
   ```json
   {
     "email": "ваш@email.com",
     "name": "Иван Иванов",
     "password": "вашпароль123"
   }
   ```
6. Нажмите "Execute"
7. Скопируйте `access_token` из ответа

### Шаг 3: Вход в систему

1. Найдите "POST /auth/login"
2. Нажмите "Try it out"
3. Заполните данные:
   ```json
   {
     "email": "ваш@email.com",
     "password": "вашпароль123"
   }
   ```
4. Нажмите "Execute"
5. Скопируйте `access_token` из ответа

## 🏗️ Как работать с проектами

### Создание проекта

Проект — это ваш рабочий контейнер для всех данных, связанных с землеустроительной работой.

1. Откройте Swagger: http://localhost:4000/api
2. Найдите "POST /projects"
3. Нажмите "Try it out"
4. Заполните данные:
   ```json
   {
     "name": "Межевание участка №1",
     "description": "Проект межевания земельного участка по адресу ул. Примерная, д. 1"
   }
   ```
5. Нажмите "Execute"
6. Скопируйте `id` созданного проекта (например, 1)

### Добавление участников

Чтобы поделиться проектом с коллегами:

1. Найдите "POST /projects/{id}/members"
2. Замените `{id}` на ID вашего проекта
3. Заполните данные:
   ```json
   {
     "userId": 2,
     "role": "editor"
   }
   ```
4. Нажмите "Execute"

Роли участников:
- **viewer** — может только смотреть
- **editor** — может редактировать
- **admin** — полный доступ

## 🗺️ Работа с географическими данными

### Создание полигона

Полигон — это граница вашего участка на карте.

1. Найдите "POST /projects/{id}/polygons"
2. Замените `{id}` на ID вашего проекта
3. Заполните данные:
   ```json
   {
     "name": "Граница участка",
     "coordinates": {
       "type": "Polygon",
       "coordinates": [
         [
           [37.6173, 55.7558],
           [37.62, 55.7558],
           [37.62, 55.76],
           [37.6173, 55.76],
           [37.6173, 55.7558]
         ]
       ]
     }
   }
   ```
4. Нажмите "Execute"

**Важно:** Координаты указываются в формате [долгота, широта]

### Создание земельного участка

Земельный участок — это детальная информация о конкретном участке земли.

1. Найдите "POST /projects/land-plots"
2. Заполните данные:
   ```json
   {
     "cadastral_number": "77:01:0001001:123",
     "area": 1500.5,
     "land_category": "Земли населённых пунктов",
     "permitted_use": "Для жилищного строительства",
     "address": "г. Москва, ул. Примерная, д. 1",
     "status": "active",
     "registration_date": "2024-01-15"
   }
   ```
3. Нажмите "Execute"

### Поиск земельных участков

Чтобы найти участок по кадастровому номеру:

1. Найдите "GET /projects/land-plots"
2. Нажмите "Try it out"
3. В поле `cadastral_number` введите: `77:01:0001001:123`
4. Нажмите "Execute"

## 📁 Работа с документами

### Загрузка документа

1. Найдите "POST /projects/{id}/documents"
2. Замените `{id}` на ID вашего проекта
3. Заполните данные:
   ```json
   {
     "name": "Акт межевания.pdf",
     "type": "assignment",
     "filePath": "/uploads/act_mezhevaniya.pdf",
     "fileSize": 1024000,
     "mimeType": "application/pdf"
   }
   ```
4. Нажмите "Execute"

## 🔍 Поиск по карте

### Поиск полигонов рядом с точкой

1. Найдите "GET /projects/polygons/search/near"
2. Заполните параметры:
   - `lat`: 55.7558 (широта)
   - `lon`: 37.6173 (долгота)
   - `radius`: 1000 (радиус в метрах)
3. Нажмите "Execute"

### Поиск полигонов в области

1. Найдите "GET /projects/polygons/search/intersects"
2. Заполните параметры:
   - `minLat`: 55.75
   - `maxLat`: 55.76
   - `minLon`: 37.61
   - `maxLon`: 37.62
3. Нажмите "Execute"

## 📊 Справочные данные

Система содержит справочники для стандартных данных:

### Категории земель
- Земли сельскохозяйственного назначения
- Земли населённых пунктов

### Типы межевых знаков
- Временный
- Долговременный

### Нормативы точности
- Максимальная точность Mt
- Допустимое расхождение площади
- Допустимое расхождение периметра

## 🔄 Жизненный цикл проекта

Проекты имеют статусы:
1. **draft** — черновик (создание)
2. **in_review** — на проверке
3. **approved** — утверждён
4. **returned** — возвращён на доработку

Для изменения статуса:
1. Найдите "PUT /projects/{id}/status"
2. Заполните данные:
   ```json
   {
     "status": "in_review"
   }
   ```
3. Нажмите "Execute"

## 💡 Полезные советы

### Как получить токен для тестирования

```bash
curl -X POST http://localhost:4000/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "ваш@email.com",
    "password": "вашпароль123"
  }'
```

### Как добавить токен в Swagger

1. Откройте Swagger: http://localhost:4000/api
2. Нажмите кнопку "Authorize" в правом верхнем углу
3. Введите токен: `Bearer ваш_токен`
4. Нажмите "Authorize"
5. Нажмите "Close"

### Как проверить, что система работает

```bash
curl http://localhost:4000/
```

Ожидаемый ответ:
```json
{
  "status": "ok",
  "message": "SA server is running"
}
```

### Как посмотреть логи

```bash
docker compose logs backend
```

## ❓ Частые вопросы

### Q: Как создать нового пользователя?
A: Используйте эндпоинт "POST /auth/register" в Swagger

### Q: Как добавить участок к проекту?
A: Создайте полигон через "POST /projects/{id}/polygons", затем создайте земельный участок через "POST /projects/land-plots"

### Q: Как найти участок по кадастровому номеру?
A: Используйте "GET /projects/land-plots?cadastral_number=77:01:0001001:123"

### Q: Как поделиться проектом с коллегой?
A: Добавьте участника через "POST /projects/{id}/members"

### Q: Как сохранить вид карты?
A: Используйте "POST /projects/{id}/map-views"

## 🆘 Решение проблем

### Проблема: 401 Unauthorized
**Решение:** Убедитесь, что токен передан в заголовке Authorization: Bearer ваш_токен

### Проблема: 403 Forbidden
**Решение:** Убедитесь, что у вас есть права доступа к проекту

### Проблема: 404 Not Found
**Решение:** Проверьте ID проекта или участка

### Проблема: 500 Internal Server Error
**Решение:** Посмотрите логи: `docker compose logs backend`

## 📞 Поддержка

При возникновении проблем:
1. Проверьте, что все сервисы запущены: `docker compose ps`
2. Посмотрите логи: `docker compose logs backend`
3. Проверьте доступность API: `curl http://localhost:4000/`

## 📝 Примечания

- Все координаты указываются в формате [долгота, широта]
- Кадастровый номер должен быть уникальным
- Для работы с географическими данными требуется PostGIS
- JWT токен действует 1 час, refresh токен — 7 дней
